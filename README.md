Jokenpô

Um projeto de Jokenpô (Pedra, Papel e Tesoura) desenvolvido para praticar conceitos fundamentais de programação e desenvolvimento de aplicações.

Sobre o projeto:

O Jokenpô é uma implementação do clássico jogo de Pedra, Papel e Tesoura.

A proposta do projeto é colocar em prática conceitos como lógica de programação, estruturas condicionais, interação com o usuário e organização de código, transformando as regras do jogo em uma aplicação funcional.

Como funciona:

O jogador escolhe uma das três opções:

- Pedra
- Papel
- Tesoura

As regras são simples:

Jogada	Vence
- Pedra	X Tesoura
- Papel	X Pedra
- Tesoura	X Papel

Quando os dois jogadores escolhem a mesma opção, ocorre um empate.

- Funcionalidades
- Jogo de Pedra, Papel e Tesoura
- Escolha entre Pedra, Papel ou Tesoura
- Identificação do resultado da partida
- Tratamento de empates
- Possibilidade de realizar novas jogadas
- Tecnologias
